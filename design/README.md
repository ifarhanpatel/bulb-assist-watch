# Design previews

[Watch overview](exports/watch-overview.png),
[iPhone welcome](exports/iphone-welcome.png), and
[connected companion](exports/iphone-connected.png) are illustrative designs,
not live bulb state or screenshots proving hardware operation.

The private development canvas contains 15 Watch states/layouts, nine companion
screens and reusable controls. The initial public source snapshot includes its
reviewed image exports, but excludes the editable `.pen` document because it
contains a document/sharing linkage identifier. The design file is not needed
to build or test the apps. Do not publish the original development history as a
substitute for the [reviewed source export](../docs/release.md).

Layouts use Inter and Lucide; see [third-party notices](../THIRD_PARTY_NOTICES.md).
The app icon's original artwork and generation prompt are in `branding/`.
