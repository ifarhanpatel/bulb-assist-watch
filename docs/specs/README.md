# Specs

This folder contains the working documents that drive implementation.

- `product-spec.md`: what we are building and why
- `technical-spec.md`: how we intend to build it
- `tasks.md`: small delivery slices tied back to the spec
- [parallel-delivery-plan.md](parallel-delivery-plan.md): ownership, execution,
  and validation for three parallel implementation streams
- [open-source-readiness.md](open-source-readiness.md): privacy, vendor terms,
  licensing, public documentation, and release verification checklist

Update these files as the source of truth when implementation changes meaningfully.
